Token Radar ranks pre-token protocols by implied launch value, with a concrete farm plan for each — built from the sealed DefiLlama snapshot of 2026-11-14. The multiples come from the snapshot itself: each category's median market-cap/TVL among the protocols in it whose token already trades.

## Run it

```sh
node main.ts --input <snapshot.json> --output out
```

Then open `out/dashboard/index.html` in a browser. No network, no install: Node 22+ standard library only.
